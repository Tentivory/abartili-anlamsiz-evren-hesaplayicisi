# Abartılı Anlamsız Evren Hesaplayıcısı

Bu repository, insanlık tarihinin en büyük sorusuna cevap vermek üzere tasarlanmıştır: **Evrenin anlamı nedir?**

Tabii ki cevap yoktur. Ama bu kod varmış gibi yapar. Üstelik abartılı bir şekilde, bilimsel terimler kullanarak, hiçbir şey hesaplamadan hesapladığını iddia eder.

## Nasıl Çalışır?

1. Programı çalıştırın.
2. Bir sayı girin (veya boş bırakın, rastgele olur).
3. Kod, evrenin anlamını "hesaplar".
4. Abartılı, felsefi, saçma sapan bir sonuç alırsınız.
5. Hayatınız değişir. Veya değişmez.

## Özellikler

- %100 gerçek çalışan Python kodu
- Hiçbir bilimsel temeli yoktur
- Türkçe abartılı cümleler üretir
- Evreni kurtarmaz ama kurtardığını söyler
- Patates içermez (söz)

## Kurulum

```bash
python evren_hesapla.py
```

Başka hiçbir şeye ihtiyacınız yok. Çay içmeniz önerilir.
